---
name: Editing submitted availability
description: Product expectations and legacy identity constraints for changing already-submitted attendance answers.
---

Make already-submitted availability directly editable from the shared attendance table, not only from the organizer's event-editing screen.

**Why:** The user clarified that changing an existing personal ○・△・× response must be discoverable where the submitted response is displayed. An organizer-only editing form did not satisfy that expectation.

**How to apply:** Preserve the existing response when re-editing it, including its comment and unanswered added dates. Do not infer that an anonymous named response belongs to a Clerk account solely because the names match; any future account linkage needs an explicit compatibility and ownership decision.
