# v1.0 プレビュー確認チェックリスト

健司さんが Replit のプレビュー環境で、手で確かめるための手順です。

所要時間の目安は 40 分です。iPhone または Outlook への取り込みと、主催者カレンダーの確認を含みます。

## 準備

主催者としてログインしたブラウザと、参加者用のシークレットウィンドウを使います。参加者側では HI-DO-RI にログインしません。

1. プレビューを開き、主催者としてログインする。Google カレンダーが接続済みであることを確認する。未接続なら接続してから先へ進む。
2. テスト用の出欠表を 1 つ作る。タイトルは後で消すと分かる名前にする（例: `v1.0プレビュー確認`）。候補は 2 件または 3 件、1 行に 1 件で入れる。1 件は日付をまたぐ夜の時間帯にする。
   1. `2026/11/18(水) 14:00〜15:00`
   2. `2026/11/19(木) 23:00〜翌1:00`
   3. `2026/11/20(金) 19:00〜20:30`（3 件目は任意）
3. 作成後の画面で「共有URLをコピー」を押す。この URL に `admin` は付いていない。
4. 別のブラウザとしてシークレットウィンドウを開く。コピーした共有 URL だけを開き、参加者の名前を入れて ○△× を送り、「入力する」で回答する。このウィンドウではログインしない。
5. 主催者のブラウザに戻る。同じ出欠表を、ログインした主催者として開く。

日付をまたぐ夜の枠は、手入力の「23:00〜01:00」のように終了が同じ日の開始より前だと、時刻として読めずカレンダー追加のボタンが出ないことがあります。必須項目 2 と 3 で時刻を見るときは、開始と終了が読める枠（例の 1 件目または 3 件目）を確定します。夜の枠を確定して終了が翌日になるかを見る場合は、その枠に開始と終了の実時刻が入っていることを先に確認します。

## 必須

### 1. 確定前はボタンが出ない

手順:

1. まだ開催日を確定していない状態で、主催者の画面の `/p/:shareId` を見る。
2. シークレットウィンドウの参加者画面でも、同じ共有 URL を見る。

期待結果:

- どちらの画面にも「Googleカレンダーに追加」は無い。
- どちらの画面にも「.icsをダウンロード（iPhone・Outlook）」は無い。
- 「開催日が確定しました」は出ていない。

結果: □OK □NG メモ:

### 2. 確定後の Google カレンダー画面が日本時間でずれない

手順:

1. 主催者画面の「主催者メニュー」で、開始と終了が分かる候補の「確定する」を押す。
2. 確認ダイアログを読み、確定する。回答受付は締め切られ、元に戻せない。
3. シークレットウィンドウの共有ページを再読み込みする。
4. 「Googleカレンダーに追加」を押す。新しいタブで開く作成画面を見る。ログインを求められても、HI-DO-RI 側のログインではない。作成画面の中身だけ確認し、予定の保存はテスト用と分かる場合だけ行う。

期待結果:

- 確定後の共有ページに「Googleカレンダーに追加」が出る。
- 開いた画面のタイトルは出欠表のイベント名と一致する。
- 開始と終了は、確定した候補の日本時間と一致する。日付も一致する。夜をまたぐ枠を確定した場合は、終了が翌日の時刻になっている。
- 説明に、その出欠表の共有 URL が含まれる。
- リンク先は Google カレンダーの予定作成で、HI-DO-RI へのログインは要求されない。

結果: □OK □NG メモ:

### 3. .ics を取り込むと同じ時刻になる

手順:

1. 確定後の共有ページで「.icsをダウンロード（iPhone・Outlook）」を押す。
2. 保存されたファイルを iPhone のカレンダー、または Outlook に取り込む。
3. 取り込んだ予定のタイトル、開始、終了を、確定した候補と比べる。

期待結果:

- ファイルがダウンロードされる。ファイル名は英数字で、`.ics` で終わる。
- 取り込んだ予定の開始と終了は、確定した候補の日本時間と一致する。
- タイトルはイベント名と一致する。
- 説明またはメモに共有 URL がある。

結果: □OK □NG メモ:

### 4. 主催者の確定と Google カレンダー同期がこれまでどおり

手順:

1. 確定前に、主催者の Google カレンダーを見る。時刻が読める候補について、タイトルが `[仮]` で始まる仮予定があることを確認する。
2. 項目 2 で開催日を確定する。確定の操作自体が、これまでどおり確認ダイアログのあとで完了することを見る。
3. 主催者の Google カレンダーを再確認する。出欠表ページの主催者向け「Googleカレンダーを確認・再同期」は、参加者向けの「Googleカレンダーに追加」とは別に残っている。

期待結果:

- 確定すると回答受付が終わり、「開催日が確定しました」と確定した候補が出る。
- その出欠表の `[仮]` 仮予定は整理され、確定した日時だけが正式な予定として残る。タイトルはイベント名で、`[仮]` は付かない。
- 参加者向けの追加リンクを押しても、主催者カレンダーへの同期の代わりにはならない。
- 同期に失敗した場合の再接続と「確認・再同期」は、これまでどおり主催者側に出る。

結果: □OK □NG メモ:

### 5. 機能追加履歴の先頭に v1.0 カードが出る

手順:

1. `/feature-history` を開く。
2. いちばん上のカードを読む。その下の v0.9 カードも見る。

期待結果:

- 先頭カードの版は `v1.0`。
- タイトルは「確定した日時を参加者が自分のカレンダーに追加できるようにした」。
- 箇条書きの 1 行目は「確定後の共有ページから、HI-DO-RIにログインせずにGoogleカレンダーへ予定を追加できる」。
- 2 行目は iPhone や Outlook 向けの `.ics` 保存、3 行目は確定するまでカレンダー追加の操作を出さない、という内容である。
- v0.9 以降の古いカードの文言は変わっていない。
- このカードの日付と時刻は、公開直前に実際の Publish 日時へ差し替える。確認の時点で日付が `2026年11月12日`、時刻が `21:32` でも、この項目では NG にしない。

結果: □OK □NG メモ:

手順:

1. 確定後の共有ページを、幅の狭い画面かブラウザのモバイル表示で開く。
2. 「Googleカレンダーに追加」と「.icsをダウンロード（iPhone・Outlook）」が読めるかを見る。

期待結果:

- ボタンの文字が画面の外に切れない。
- 2 つの操作と「確定日時をコピー」が押せる。

結果: □OK □NG メモ:

### 7. 「確定日時をコピー」が引き続き使える

手順:

1. 確定後の共有ページで「確定日時をコピー」を押す。
2. メモ帳などに貼り付ける。

期待結果:

- 「コピーしました」になる。
- 貼り付けた文に、イベント名、確定した日時、共有 URL が含まれる。

結果: □OK □NG メモ:

## 片付け

テスト用の出欠表を削除する画面は無い。共有 URL を他の人へ渡さない。

1. 主催者の Google カレンダーから、このテストで入った予定を消す。`[仮] v1.0プレビュー確認` のような仮予定が残っていればそれも消す。確定予定（`[仮]` の付かない同じタイトル）も消す。
2. iPhone または Outlook に取り込んだテスト予定があれば消す。
3. Google の作成画面で予定を保存していた場合は、その予定も消す。
4. プレビュー上の出欠表は残ってよい。タイトルでテスト用と分かる状態のままにする。

結果: □OK □NG メモ:
