# v1.1 プレビュー確認チェックリスト

## 事前準備

1. 開始時刻と終了時刻を含む手動候補日を2〜3件登録して出欠表を作成
2. テスト用参加者2〜3名で回答を入力（○・△・×を混在させる）
3. 主催者として候補日のうち1つを確定

## 確認項目

### 回答マトリクスの表示

1. 確定後のページで、回答マトリクステーブルが表示されていることを確認
2. 確定した候補日の列**のみ**が表示され、他の候補日の列は非表示になっていることを確認
3. 参加者名、コメント、○△×記号が正しく表示されることを確認
4. サマリー行（○の数）が表示されることを確認
5. 回答が0件の場合、「まだ回答がありません」と表示されることを確認

### 確定候補日の列

1. 確定した候補日の列ヘッダーに「確定」バッジが表示されることを確認
2. バッジのデザインが適切であることを確認（背景色・テキスト色・サイズ）

### 確定カードの集計情報

1. 「開催日が確定しました」カード内に「○ N人・△ N人・× N人」の集計が表示されることを確認
2. 集計の数値が実際の回答データと一致することを確認
3. ○をつけた参加者の名前が「参加予定: 〜」として列挙されることを確認
4. 回答が0件の場合、「回答はありません」と表示されることを確認

### 非表示要素の確認

1. 確定後に回答変更フォームが表示されないことを確認
2. 「回答を変更」ボタンが表示されないことを確認
3. ラジオボタンによる入力欄が表示されないことを確認

### カレンダーボタン

1. 「Googleカレンダーに追加」ボタンが機能することを確認
2. 「.icsをダウンロード」ボタンが機能することを確認
3. ダウンロードした.icsファイルにイベント情報が含まれることを確認

### レスポンシブ確認

1. モバイル幅（~390px）でページを表示し、レイアウトが崩れないことを確認
2. 回答マトリクステーブルが横スクロール可能であることを確認
3. 確定カードがモバイル幅で適切に表示されることを確認

### 権限とアクセス

1. 共有URLを持つ参加者が確定後の回答表を閲覧できることを確認
2. 管理URLなど新たな情報が不適切に公開されていないことを確認
3. 確定前に見えていた情報と確定後に見える情報の範囲が同一であることを確認

## 回帰テスト

1. 確定前の出欠表ページが正常に表示されることを確認
2. 確定前の回答入力フォームが正常に機能することを確認
3. 主催者メニューが正常に表示されることを確認
4. 他の既存機能が正常に動作することを確認
