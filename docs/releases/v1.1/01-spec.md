# v1.1 機能仕様

## 概要

日程確定後も、参加者の○△×回答を確認できるようにする機能を追加。

## 詳細仕様

### 1. 確定後の回答マトリクス表示

- `poll.isClosed === true` の場合でも、回答マトリクステーブルを表示する
- 表示する列は**確定した候補日のみ**とし、他の候補日の列は非表示
- 表示内容:
  - 参加者名
  - コメント（入力されている場合）
  - 確定した候補日への回答（○・△・×）
  - サマリー行（○の数）
- 読み取り専用とし、以下を非表示:
  - 回答変更フォーム
  - 「回答を変更」ボタン
  - ラジオボタン入力欄

### 2. 確定候補日の列ヘッダー

- 確定した候補日の列ヘッダーに「確定」バッジを表示
- バッジデザイン: `bg-primary` 背景、`text-primary-foreground` テキスト、角丸、小サイズ

### 3. 確定カードへの集計情報追加

「開催日が確定しました」カード内に、確定した候補日への回答集計を追加:

- **回答がある場合:**
  - `○ N人・△ N人・× N人` 形式で集計を表示
  - ○をつけた参加者の名前を列挙（例: 「参加予定: 山田、佐藤、鈴木」）
- **回答がない場合:**
  - 「回答はありません」と表示

集計は実際の `poll.responses` データから算出し、架空のデータは使用しない。

### 4. カレンダーボタン

既存の「Googleカレンダーに追加」「.icsをダウンロード」ボタンは変更なし。

### 5. レスポンシブ対応

- モバイル幅（~390px）でも正常に表示されること
- テーブルは既存の横スクロール機能を維持

### 6. 可視性ルール

- 確定前と確定後で、同じ共有URLを持つ閲覧者が見られる情報の範囲は同一
- 新たな情報（例: 管理URL）を公開しない
- 共有リンクを持つすべての人が確定後の回答表を閲覧可能（確定前と同様）
