# v0.6 仕様書

## 要件

`/feature-history` ページにv0.6のリリースカードを追加し、日本語条件からの候補日時解釈の改善内容を掲載する。

## 背景

2026年9月12日にparseCondition関数の改善が本番環境に反映された。これにより、日付範囲・時間帯の解釈がより正確になった。これらの改善内容を機能履歴ページで公開する必要がある。

## 仕様

### バージョン情報
- **version**: `v0.6`
- **date**: `2026年9月12日`
- **time**: `18:15`
- **title**: `日本語条件からの候補日時生成を強化`

### 機能リスト（以下の5項目のみ）
1. `年付きの日付範囲（例: 2026/9/18-9/22）を正しく解釈`
2. `「午後」「午前」「夜」だけの指定でも時間帯を適用`
3. `コロン付きの時刻範囲（例: 13:00-15:00）を正しく解釈`
4. `「○月○日から○日の間」形式の日付範囲に対応`
5. `条件が取れないときに意図と違う 30日デフォルトへ落ちにくく改善`

### 実装詳細
- `artifacts/hidori/src/pages/feature-history.tsx` の `releases` 配列の先頭にカードを追加
- 既存のv0.1〜v0.5カードは変更しない
- 既存のカード形式とトーンを厳密に踏襲
- 箇条書きの末尾に句読点は付けない
- 名詞・動詞句形式を使用

## 成功基準

1. v0.6カードが `releases` 配列の先頭に表示される
2. 上記5つの機能が正確に記載されている
3. v0.5および過去のバージョンカードが変更されていない
4. カードのフォーマットがv0.1〜v0.5と一致している
5. 日本語表現とトーンが既存カードと統一されている
6. 追加機能や架空の内容が含まれていない
