# v0.6 機能履歴掲載内容

## `/feature-history` ページに追加されたカード内容

### バージョン
v0.6

### 日付
2026年9月12日

### 時刻
18:15

### タイトル
日本語条件からの候補日時の解釈を改善

### 機能リスト

1. 「2026/9/18-9/22」のような日付範囲を、今後30日に広げず指定期間だけに限定

2. 「午後」を13:00〜18:00として解釈

3. 「13:00-15:00」のようなコロン付き時刻範囲をそのまま採用

4. 期間や時間帯が読み取れたときは、毎日19:00〜の初期値へ戻さない
