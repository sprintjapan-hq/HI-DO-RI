# v0.6 機能履歴掲載内容

## `/feature-history` ページに追加されたカード内容

### バージョン
v0.6

### 日付
2026年9月12日

### 時刻
18:15

### タイトル
日本語条件からの候補日時生成を強化

### 機能リスト

1. 年付きの日付範囲（例: 2026/9/18-9/22）を正しく解釈

2. 「午後」「午前」「夜」だけの指定でも時間帯を適用

3. コロン付きの時刻範囲（例: 13:00-15:00）を正しく解釈

4. 「○月○日から○日の間」形式の日付範囲に対応

5. 条件が取れないときに意図と違う 30日デフォルトへ落ちにくく改善
